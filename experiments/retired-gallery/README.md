# Retired gallery experiments

These graphs are preserved for reference, outside the curated examples shelf.

- `alishan-fog-dawn`: hardcodes its location despite offering an editable place. It and the later postcard wrapper were retired from the catalog.
- `custom-endpoint`: an HTTP echo tutorial, not a useful completed task. Its picker does not change the endpoint; running sends the entered text to a third-party echo service. Consult the custom endpoint guide when wiring a service.
