## Notes

One object idea becomes a textured 3D model. GLM 5.3 Flash writes a concept description of the object (silhouette, parts, materials, colors, everything solid and connected). A Join node adds fixed 3D-ready render rules: one whole object, three-quarter view, plain light-gray background, no props. Muse paints the concept, and TRELLIS.2 turns that single picture into a GLB with embedded textures.

Change **Object idea**: one solid object, family-friendly. The graph exports the **TRELLIS.2 → GLB** model. The concept description, prompt and concept image are intermediates you can see on the canvas.

Defaults are TRELLIS.2 at 1024 geometry, 1024 px textures and about 80k faces. On 12 October 2026 the saved run reported $0.21: $0.20 for TRELLIS.2, $0.01 for Muse and under $0.0001 for the GLM call. Prices are observations, not caps. Swap in Tripo 2.5 or Hunyuan on the 3D node to trade price for detail.

The saved run is in the nanoodle gallery (https://nanoodle.com/examples/gallery/#idea-to-3d-model): a teal-and-cream wind-up toy submarine with a brass periscope, portholes, a wind-up key and a striped tail. The 3.6 MB GLB holds up from every side, including the far side the picture never showed. Flaws: nanoodle's viewer shades it flatter than the concept, the thin key and propeller blades go soft at some angles, and the far-side cream band is a plainer flat strip. Inspired by @patchmonkeydev's prompt → concept → multi-view → 3D ComfyUI pipeline (https://x.com/patchmonkeydev/status/2109453424643428622); only the idea is used.
