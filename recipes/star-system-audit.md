## Notes

Ask an image model for a star-system poster and it will happily invent the astronomy: a gorgeous spiral of planets, two of them sharing an orbit, a ringed giant where a small red world should be — and the poster looks so authoritative that nobody counts it back to the plan. This graph makes the poster answer for its system. A GLM astronomer writes a system spec from a brief — an invented star name as the title, exactly six planets numbered from orbit 1 (innermost) to orbit 6 (outermost), each with its own dominant colour and one signature feature (a wide ring, one large moon, bold stripes, a white ice cap, a red storm spot, many craters) — a second GLM turns the spec into a poster-design brief, and Muse renders the poster: one glowing star at the centre, six thin concentric orbit circles, exactly one planet per orbit in its planned colour showing its planned feature, every planet name printed beside its planet. Then a Gemini vision poster checker reads the planets back from the innermost orbit out, with the colour and feature it can see on each, a GLM auditor scores the spec against that read-back planet by planet (PLACED / WRONG ORDER / MISSING across all six orbits, DETAIL lines for any colour or feature that drifted, EXTRA lines for any planet that was never in the spec, ending in an "X of 6 placed" summary), and a ⚖️ Decide judge (PPLX Decider) gives the headline verdict: **charted to spec**, **order drifted**, **planets missing**, or **wrong system**. The poster is not decoration here; it is a claim about a system — which planets, on which orbits, in which colours, carrying which features — and two independent reads hold it to that claim.

Why the loop matters: an orbit diagram is a data chart wearing a poster's clothes. Its failures are not ugly pixels but wrong facts — a planet on the wrong orbit still looks like a planet, and a swapped colour quietly teaches the wrong system to anyone who hangs the poster. Splitting the jobs across four model families is what makes the check honest: the model that invented the system is not the model that drew it, and neither of them reads it back. The concentric layout is the design's keystone: because each planet owns exactly one orbit ring, position itself is a checkable fact — a planet is on its ring or it is not — and the audit scores the astronomy, not the styling.

Honest limits, in the open: the poster check reads a 512 px shrink of the render, so small labels and subtle features on the inner orbits are judgement calls, and the checker's "(?)" guesses flow straight into the audit — read the DETAIL lines against the poster yourself before you trust them. Planet names are matched loosely (a close spelling counts as the same planet), so a subtly renamed label can pass. The auditor scores names, orbits, colours and features; it does not measure scale — a planet drawn far too large for its orbit still counts as placed if it sits on the right ring, and only the Decide judge, looking at the whole image, can catch a poster that is astronomically right but visually misleading. The system is invented by the astronomer — this proves a poster can be made to carry a planned system faithfully, not that any real system looks like this. And six planets is a design choice, not a law — edit the astronomer's system prompt and the auditor's summary line together if your system runs larger, knowing every added planet makes the render and the read-back harder. One deliberate guard from this catalog's own repair history: the poster-brief node is capped (maxTokens 300, reasoningEffort low, the pairing the mural-wall repair landed on), because an uncapped brief generation on a detailed plan once ran past the HTTP timeout three runs in a row. The audit node carries the same medicine (maxTokens 400, reasoningEffort low) — added after the second live attempt below, when the uncapped auditor timed out on a long read-back; the capped auditor answered the identical input in about six seconds during isolated diagnosis.

Expected cost per run: Muse text-to-image $0.011, the Gemini poster check $0.002–0.031 (it billed $0.0310 on the second live attempt — the run's real cost driver), the three GLM calls effectively $0.00, and the Decide audit is not priced in the 2026-09-12 catalog snapshot — expect roughly $0.02–0.05 all in.
