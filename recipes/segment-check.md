## Notes

A seven-segment digit is not a numeral shape: it is a set of seven bars, and the digit exists only through which bars are lit. Light the middle bar of a 0 and it silently becomes an 8; drop the lower-left bar from an 8 and it turns into a 9 - a different, perfectly valid digit wearing the first one's body; take the middle bar away from a 2 and its bars state no digit at all. And the number on this display is itself derived before it is drawn: a start time plus a count of elapsed minutes, minutes carrying into hours, hours wrapping at midnight, so the four digits are an arithmetic result before they are a segment pattern. Image models paint LED clocks as glowing props - handsome red digits that are almost a time, bars lit by vibe, a 9 with a lower-left bar glowing for no reason. This flow makes both derivations planned, measurable quantities - and then it does something about a lying digit. Give it a plain display backdrop and a GLM director picks one reading from a menu printed in its own prompt (BAKE TIMER 08:35 + 47 minutes = 09:22, LAST TRAIN 11:48 + 29 = 12:17, MIDNIGHT WHISTLE 23:51 + 18 = 00:09 past the midnight wrap - every display time already derived, and every digit's lit segment set spelled out through the standard seven-segment table) and copies it onto a DISPLAY CARD. A second GLM turns the card into one painter prompt demanding a single straight-on photograph of a black LED display panel: four large red digits and a glowing colon, each digit lighting exactly its carded segments and no others. Muse paints it. A blind Gemini reader, who never saw the card, reports only which segments are brightly lit on each digit, by position name - TOP, UPPER-LEFT, UPPER-RIGHT, MIDDLE, LOWER-LEFT, LOWER-RIGHT, BOTTOM - counting a segment only when it glows, never from a faint unlit outline. A GLM auditor decodes each read set through the same table by exact set-match and scores the picture digit by digit - EXACT, VALID-WRONG (the read set is exactly some other digit's set, and the auditor names the digit it actually states), INVALID (the set is no digit at all) or UNREADABLE - with SEGMENTS out of 28, DECODED out of 4 and the COLON scored separately: DISPLAY TRUE only when all four decoded digits equal the carded display time and the colon stands. A Decide judge (PPLX Decider) sees the picture and all the texts and gives the headline verdict on round 1 as a side output.

Why the loop matters: the catalog's other code audits each decode one layer - resistor check reads colours as arithmetic symbols, braille check reads dot positions as letters, clock check reads hand angles as a time someone carded directly. Here two derivations stack: the displayed time is computed (start plus elapsed, with the carry and the midnight wrap), and each resulting digit is then encoded as a segment set, so the certificate is a chain, not a copy. The segment layer also splits one failure into two mechanically different diseases that no neighbouring audit can tell apart: a digit whose bars state a different valid digit (DIGIT LYING - the display is readable, confident, and wrong) and a digit whose bars state nothing at all (SEGMENTS BROKEN - the display is visibly nonsense). They have different repairs, and the audit names which one happened, digit by digit. Per the owner's end-in-the-asset rule, the audit is not the deliverable: a gated GLM editor turns any failure into concrete repaint notes for the failing digits only (a true display demands a verbatim copy; the honest digits are never repainted to fake a match, and a missing colon is restored on its own line), Muse Edit repairs the photograph, and a blind re-read plus the same auditor re-score the corrected picture, which is the flow's final output.

What it does not prove: whether a segment glows or merely shows as a faint unlit outline is a blind reader's judgement on painted pixels, and real LED photographs sit exactly on that boundary - the audit scores the reader's words, so a reader who promotes a ghost outline to lit and a painter who over-lights a bar are indistinguishable in the score and are told apart, if at all, by looking at the pixels. The time arithmetic is verified in code offline and copied by the director; nothing here measures a real clock's accuracy. One run proves the chain - director, brief, paint, blind segment read, set decode, gated digit repair, re-audit - end to end on the reading the director happened to pick.
