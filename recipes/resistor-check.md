## Notes

A resistor is a number wearing colours. Nothing on its body is a digit: the value lives in a code - the first band is a digit, the second band is a digit, the third band is a power of ten, and a gold band at the far end only promises the value is honest to five percent. Yellow, violet, brown is not a decoration, it is 47 x 10 = 470 ohms, and the same three bands read backwards state 170,000 ohms - the code is order-sensitive, multiplier-sensitive, and completely invisible to anyone who reads the stripes as a pattern instead of a number. Image models paint resistors exactly that way: handsome beige cylinders with plausible stripes that decode to nothing in particular, because no single stripe looks wrong. This flow makes the code a planned, measurable quantity - and then it does something about a misbanding. Give it a plain workbench backdrop and a GLM director picks one trio from a menu printed in its own prompt (WORKBENCH 470 / 1000 / 22000 ohms, DRAWER 330 / 5600 / 15000, SPARE 7800 / 41 / 680 - every value derived through the standard colour-code table and printed on the card) and copies it onto a RESISTOR CARD: each resistor's three code bands in reading order, its gold tolerance band, and its decoded value. A second GLM turns the card into one painter prompt demanding a single macro photograph of the three resistors in a row on the bench, each body carrying exactly its four carded bands in card order with gold at the right end. Muse paints it. A blind Gemini reader, who never saw the card, reports only the band colours it can see on each resistor, left to right. A GLM auditor decodes the read bands through the same table and scores the picture resistor by resistor - EXACT, REVERSED (the code bands landed in reverse order), WRONG BAND or UNREADABLE - with CODE BANDS out of 9, TOLERANCE out of 3 and VALUES out of 3: TRUE VALUE only when all three decoded values equal the carded ones. A Decide judge (PPLX Decider) sees the picture and all the texts and gives the headline verdict on round 1 as a side output.

Why the loop matters: the catalog's other colour audits use colour as a property - paint-mix check mixes colours by algebra, ishihara check hides a figure in hue, thermal check ranks colours by heat. Here colour is neither mixed nor matched: it is READ, as symbols in a conventional code whose meaning is arithmetic. A band can be a perfectly painted colour and still be the wrong symbol - brown where red belongs is a flawless stripe and a tenfold lie about the value - and no single band can certify a resistor: the certificate is the decoded number, which exists only when all three bands are decoded together, in order, through the table. Per the owner's end-in-the-asset rule, the audit is not the deliverable: a gated GLM editor turns any misbanding into concrete repaint notes for the failing resistors only (a true-value audit demands a verbatim copy; the honest resistors are never repainted to fake a match), Muse Edit repairs the photograph, and a blind re-read plus the same auditor re-score the corrected picture, which is the flow's final output.

What it does not prove: a band's colour is a blind reader's judgement on painted pixels, and the classic confusable neighbours (brown / red / orange under warm light) are exactly where a reader's call can honestly differ - the audit scores the reader's words, so a naming wobble and a painting error are indistinguishable in the score and are told apart, if at all, by looking at the pixels. The gold tolerance band certifies position and reading direction only; nothing here measures a real resistor. One run proves the chain - director, brief, paint, blind band read, table decode, gated band repair, re-audit - end to end on the trio the director happened to pick.
