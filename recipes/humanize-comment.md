## Notes

Rewrites a short draft comment so it reads like a person typed it, without changing what it says. Four writers rewrite the same draft in parallel: three community anti-slop finetunes (Qwen3.8-27B antislop, Gemma-4-31B StyleTune, Orion-26B-A4B v1.1) and Gemini 3.8 Flash. Each rewrite is joined under a fixed label ([A]..[D]) next to the [ORIGINAL] draft and the post context, and a GLM-5.3 decider picks the most human-sounding rewrite that keeps every fact, number, name, link, question and disclosure. If every rewrite breaks a rule it returns ORIGINAL. The label text nodes are needed: without them the decider mixed up which label went with which text.

Inputs: **Draft** (the comment to rewrite, up to about 1500 characters, any language), **Context** (the post or thread, plain text, up to about 3500 characters) and optional **Guidance** (what the comment should do; default "a friendly, specific reply"). The writer and decider instructions are written for Nano Maxi, an openly AI agent account on Subnano, and they are editable like any other input; change them to fit your own voice. The graph exports the decider's text: one JSON object {"winner": "ORIGINAL|A|B|C|D", "disqualified": {...}, "why": "...", "text": "..."}, where text is the winning rewrite. A = antislop, B = StyleTune, C = Orion, D = Gemini Flash. Check the facts before you post it.

On 19 October 2026 a run through the nanoodle npm engine 0.9.0 (via nanoodle-mcp's tool loader) reported $0.0023 and took 48 s, on a dev-forum post about cutting CI time from 14 to 6 minutes plus a stiff, formal draft reply. The decider picked B and disqualified A (said the Playwright flag splits by duration, a wrong fact), C (dropped the AI-agent disclosure) and D (hype). Earlier local runs of the same models cost $0.0028 to $0.0032. The catalog forecast, which assumes every node uses its full maxTokens, is $0.011. Prices are observations, not caps.

Hosted on mcp.nanoodle.com the graph pins an x402 deposit of $0.015 (about 0.046 XNO at $0.33/XNO): it covers the full-maxTokens forecast plus 20% ($0.013), and the run settles at real cost plus 20% with the rest returned as change. Limits: the engine has no per-node timeout and a failed writer fails the whole run (it does not pass an empty block to the decider); community-hosted writers are sometimes slow, and the run above took 48 s end to end.
