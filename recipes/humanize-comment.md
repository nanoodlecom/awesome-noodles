## Notes

Rewrites a short draft comment so it reads like a person typed it, without changing what it says. This is Nano Maxi's humanize-comment flow v2.3. Four writers rewrite the same draft in parallel: three community anti-slop finetunes (Qwen3.8-27B antislop, Gemma-4-31B StyleTune, Orion-26B-A4B v1.1) and Gemini 3.8 Flash. Each rewrite is joined under a fixed label ([A]..[D]) next to the [ORIGINAL] draft and the post context, and a GLM-5.3 decider picks the most human-sounding rewrite that keeps every fact, number, name, link, question and disclosure. If every rewrite breaks a rule it returns ORIGINAL. The label text nodes are needed: without them the decider mixed up which label went with which text. v2.3 tells the writers to keep the draft's warmth and enthusiasm while removing slop, and bans Nano Maxi's worn-out filler phrases.

Inputs: **Draft** (required; the comment to rewrite, up to about 1500 characters, any language), **Context** (required; the post or thread, plain text, up to about 3500 characters) and optional **Guidance** (what the comment should do; default "a friendly, specific reply"). The graph exports the decider's text: one JSON object {"winner": "ORIGINAL|A|B|C|D", "disqualified": {...}, "why": "...", "text": "..."}, where text is the winning rewrite.

All 10 prompt and label args are exposed as optional inputs; omit them to keep the defaults below (the spec's v2.3 values), or override them to fit your own voice:
- **Writer A (Qwen3.8-27B antislop)**, **Writer B (Gemma-4-31B StyleTune)**, **Writer C (Orion 26B-A4B v1.1)**, **Writer D (Gemini 3.8 Flash)**: each writer's system prompt. Default: the identical v2.3 writer prompt (Nano Maxi's voice; keep every fact, number, name and link; stay openly an AI agent; no em dashes, emoji sign-offs or banned filler phrases; keep the draft's warmth; 2 to 4 sentences).
- **Decider (GLM-5.3)**: the decider's system prompt. Default: the v2.3 decider rubric (pick the most human rewrite, disqualify any fact, qualifier, link or disclosure change, fall back to ORIGINAL, reply with JSON only).
- **Label ORIGINAL**, **Label A**, **Label B**, **Label C**, **Label D**: the label line put above each block the decider reads. Defaults: "[ORIGINAL]", "[A]", "[B]", "[C]", "[D]". Change them only together with the decider prompt, which refers to those labels.

On 19 October 2026 one v2.3 run through the nanoodle npm engine 0.9.0 (via nanoodle-mcp's tool loader) reported $0.0024 and took 13 s, on a dev-forum post about cutting CI time from 14 to 6 minutes plus a stiff, formal draft reply. The decider picked B and disqualified none. An earlier v2.2 run on the same sample reported $0.0023 and took 48 s. The catalog forecast, which assumes every node uses its full maxTokens, is $0.011. Prices are observations, not caps.

Hosted on mcp.nanoodle.com the graph pins an x402 deposit of $0.0168, which is 0.05 XNO at the NanoGPT x402 rate of $0.3369/XNO on 19 October 2026 (the rate nanoodle-mcp itself quotes at). A pinned price is used as the deposit as is, with no extra multiplier, so the deposit is about 0.0499 XNO plus a tiny matching tag; the run settles at real cost plus 20% and the rest comes back as change. The XNO amount moves with the rate.

Known limitation (nanoodle 0.9.0): the engine has no per-node timeout, so the spec's 60 s writer timeout is not enforced, and there is no failed-writer fallback. A writer error (for example an HTTP 400 from one writer's host) stops the run before the decider runs; the writer does not pass an empty block to the decider, so one failed writer fails the whole run. Community-hosted writers are sometimes slow.
