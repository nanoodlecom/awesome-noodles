## Verification and limits

The curation pass read every graph and its connections, checked advertised inputs against prompts, and looked up image/video/audio capability and price metadata in the public NanoGPT catalogs on 2026-09-05. All retained model IDs were also checked against the live catalogs by the repository model audit. Catalog metadata supports routing and parameter choices; it does not prove aesthetic quality, prompt adherence, factual accuracy or provider reliability.

README share links are regenerated from exact committed graph JSON and checked with `npm test`. Output acceptance criteria above are requirements, not assertions that new generations passed. The existing character example has committed game/artifact evidence; twelve rewritten workflows now have saved outputs and explicit review notes in the [sample gallery](https://nanoodle.com/examples/gallery/). Image/text inspection, sampled video frames and model-assisted audio review are identified separately; none is a guarantee for future runs. The final avatar uses a male presenter to match the selected male voice; its sampled frames and model-assisted audio transcript passed their stated checks. Precise lip-sync timing is left visible for playback judgment.

Primary catalog sources: [chat](https://nano-gpt.com/api/v1/models?detailed=true), [image](https://nano-gpt.com/api/v1/image-models), [video](https://nano-gpt.com/api/v1/video-models), [audio](https://nano-gpt.com/api/v1/audio-models). Text cost depends on tokens; media estimates exclude text, retries and optional higher settings.

Initial live checks: the revised `deslop` completed at approximately $0.0079 and retained the supplied facts in output review. The first mockup revision failed because the LLM-expanded prompt exceeded the provider’s 800-character cap; the graph now bypasses that LLM and joins a 696-character default brief and style directly. Subsequent output validation is recorded by the session lead.

Image output review: favicon passed for a crisp navy/gold glyph; FIBO returned a coherent amber pump bottle at 1024×1024 (its unsupported `aspect` field was removed); the postcard returned a coherent illustrated night market. All four arena outputs rendered the specified text correctly, but only Grok depicted recognizable tire levers; Krea produced fork-like tools, Recraft pry-bar-like tools and Muse brake-lever-like tools. This is useful task-specific differentiation, not a universal model ranking. Video API calls completed at $0.21 for photo-to-video and $0.195 for the turntable; completion alone does not establish temporal quality.


Final useful-input checks: replacing the postcard place with a dry sandstone arch produced a desert illustration with no market scenery; replacing the FIBO bottle with a red canvas sneaker produced the requested shoe with no bottle materials. These two runs reported $0.01 and $0.04 respectively. The final 696-character mockup prompt produced the exact requested rows, names, statuses, navigation and totals without invented extra sections. Product cleanup and two-reference placement produced plausible images from generated source photos, with exact merchandise fidelity left for source comparison.

The 170-second song completed at $0.225. Gemini 3.8 Flash reviewed its audio for an additional reported $0.00627, transcribed the intended chorus and reported clear acoustic vocals without obvious glitches. This is model-assisted audio assessment, not human listening sign-off. The saved audio and generated lyrics let a visitor judge it directly.

Validation: all 13 graphs materialize without warnings in both local JavaScript and Python runners, and their exposed input/output contracts agree. All 28 model-bearing nodes pass the corrected live capability/settings audit. README links round-trip; gallery-to-source parity, JavaScript syntax, five-language coverage and the sample-page asset/hash checks pass. Desktop and 390px mobile browser checks found no page errors or horizontal overflow. The gallery graphs, website sample assets and MCP listings form one release; their public links must resolve together.

The final graph makes the male presenter explicit, and the featured run completed with at least $0.28 reported. Sampled frames preserve identity and plausible facial movement; Gemini 3.8 Flash transcribed the supplied workshop script exactly and reported clear baritone speech. The sample discloses the several-minute generation time and does not claim frame-accurate lipsync measurement.
