## Verification and limits

The curation pass read every graph and its connections, checked advertised inputs against prompts, and looked up image/video/audio capability and price metadata in the public NanoGPT catalogs on 2026-09-05. All retained model IDs were also checked against the live catalogs by the repository model audit. Catalog metadata supports routing and parameter choices; it does not prove aesthetic quality, prompt adherence, factual accuracy or provider reliability.

README share links are regenerated from exact committed graph JSON and checked with `npm test`. Output acceptance criteria above are requirements, not assertions that new generations passed. The existing character example has committed game/artifact evidence; twelve rewritten workflows now have saved outputs and explicit review notes in the [sample gallery](https://nanoodle.com/examples/gallery/). Image/text inspection, sampled video frames and model-assisted audio review are identified separately; none is a guarantee for future runs. The final avatar uses a male presenter to match the selected male voice; its sampled frames and model-assisted audio transcript passed their stated checks. Precise lip-sync timing is left visible for playback judgment.
