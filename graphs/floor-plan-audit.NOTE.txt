# recipe-note
Ask an image model for a floor plan and it will happily invent the architecture: a handsome drawing with eight rooms where seven were planned, the bathroom marooned in the wrong corner, a sofa in the kitchen — and the plan looks so authoritative that nobody checks it back against the layout. This graph makes the drawing answer for its home. A GLM architect writes a layout spec from a brief — an invented home name as the title, exactly seven rooms in a fixed order (LIVING ROOM, KITCHEN, BEDROOM, BATHROOM, HALLWAY, STUDY, BALCONY), each placed in its own zone of a 3-by-3 grid (north-west through south-east, no two rooms sharing a zone) and each carrying one signature fixture a plan can draw from above (an L-shaped sofa, an island counter, a double bed, a bathtub, a runner rug, a corner desk, deck chairs) — a second GLM turns the spec into a plan-drawing brief, and Muse renders the plan: black wall outlines on white, seen directly from above, every room labelled in capitals inside its own space, every fixture drawn in its room, the front door opening into the hallway. Then a Gemini vision plan checker reads the rooms back in grid reading order, with the zone each room's centre falls in and the fixture it can see, a GLM auditor scores the spec against that read-back room by room (PLACED / WRONG ZONE / MISSING across all seven rooms, DETAIL lines for any fixture that drifted, EXTRA lines for any room that was never in the spec, ending in an "X of 7 placed" summary), and a ⚖️ Decide judge (PPLX Decider) gives the headline verdict: **planned to spec**, **zones drifted**, **rooms missing**, or **wrong plan**. The plan is not decoration here; it is a claim about a home — which rooms, in which zones, carrying which fixtures — and two independent reads hold it to that claim.

Why the loop matters: a floor plan is a data diagram wearing a drawing's clothes. Its failures are not ugly pixels but wrong facts — a bedroom in the kitchen's zone still looks like a bedroom, and a missing balcony is invisible until someone counts. Splitting the jobs across four model families is what makes the check honest: the model that invented the layout is not the model that drew it, and neither of them reads it back. The 3-by-3 grid is the design's keystone: because each room owns exactly one zone, position itself is a checkable fact — a room's centre is in its zone or it is not — and the audit scores the layout, not the styling. Room-makeover tools edit a photo of a room you already have; this flow invents the whole home on paper and then audits the invention.

Honest limits, in the open: the plan check reads a 512 px shrink of the render, so small labels and simple plan symbols are judgement calls, and the checker's "(?)" guesses flow straight into the audit — read the DETAIL lines against the plan yourself before you trust them. A room's zone is judged by where its centre falls, so a room that straddles a grid line can be scored either way by the read-back; the audit inherits that call. Room labels are matched loosely (a close spelling counts as the same room), so a subtly garbled label can pass. The auditor scores names, zones and fixtures; it does not measure areas or check that doors and walls actually connect — a plan can be zoned perfectly and still be unbuildable, and only the Decide judge, looking at the whole image, can catch a plan that is layout-right but architecturally absurd. The home is invented by the architect — this proves a plan can be made to carry a planned layout faithfully, not that any real home should be built from it. And seven rooms in nine zones is a design choice, not a law — edit the architect's system prompt and the auditor's summary line together if your home runs larger, knowing every added room makes the render and the read-back harder. Two deliberate guards from this catalog's own repair history: the plan-brief node is capped (maxTokens 300, reasoningEffort low, the pairing the mural-wall repair landed on), because an uncapped brief generation on a detailed plan once ran past the HTTP timeout three runs in a row; the audit node carries the same medicine (maxTokens 400, reasoningEffort low). The Decide node names perplexity/pplx-decider-v1.2 — NanoGPT retired v1.1-27b (410 model_retired), and every older catalog graph still naming v1.1-27b will fail at its Decide node until it is swapped the same way.

Expected cost per run: Muse text-to-image $0.011, the Gemini plan check roughly $0.002–0.031 (its price swings run to run — it is the run's real cost driver when it bills high), the three GLM calls effectively $0.00, and the Decide audit is not priced in the report — expect roughly $0.01–0.05 all in. Prices are observations, not caps.
