# recipe-note
One character brief becomes an animatable 3D character. GLM 5.3 Flash expands the brief into a rig-ready character description (humanoid build, every part solid and connected), a Join node adds fixed reference rules — full body in a strict T-pose on plain white — and Nano Banana paints the reference. Tripo 2.5 lifts that single picture into a 3D statue. Then the mesh itself travels the model wire into Hyper3D Rigging, a mesh-processing model that cannot run without an existing model: it fits a human skeleton and skin weights and returns a GLB that can be posed and animated, not just orbited.

Change **Character brief**: one humanoid character (two arms, two legs — the rig uses the human bone template), family-friendly. The graph exports the **Rigged model** node. The description, prompt, reference image and statue are intermediates you can see on the canvas.

Proof is structural: a rigged model is verified by parsing the returned GLB for its skin (JOINTS_0 / WEIGHTS_0 vertex attributes and a skins entry with joints), never by looking at a render. Live proof (2026-11-17, robot gardener brief): all nodes done, $0.5390 balance-verified (Nano Banana $0.039, Tripo statue $0.30, Hyper3D rigging $0.20, GLM $0.00). The rigged GLB (19,633,856 bytes) parses with JOINTS_0 + WEIGHTS_0 attributes and one skin of 52 joints across 54 nodes; the statue GLB it came from (12,805,784 bytes) has no skin and no JOINTS attributes — the control that proves the rigging leg, not the generator, added the skeleton. Three earlier verification attempts were interrupted by service restarts and a fourth failed at the rig node ("Add a prompt or connect an image first") because the headless runner loaded no model catalog, so the executor never recognised hyper3d/rigging as a mesh-input model and ignored the model wire; the runner now passes the live 3D catalog, matching the editor.

Headless note: running this graph outside the editor needs an executor with the model3d mesh input (nanoodle-js #66 / nanoodle-py #22); published packages without it cannot pass the statue's mesh to the rigging node. Prices are observations, not caps.
