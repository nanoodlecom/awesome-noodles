# recipe-note
Regional prompting the ComfyUI way — sequential masked inpainting — rebuilt as three chained Inpaint passes. In ComfyUI you would paint a mask per region and run one inpaint per region so a finished area is never re-rolled by the next prompt; this graph does exactly that. Each pass takes the previous pass's output as its source, its own mask (white = repaint, black = keep, at the photo's full pixel size), and its own one-line prompt: what goes in that region, and nothing else. The defaults restyle one plain room in three passes: a framed painting, a houseplant, a side table. Change the three **Region — paint this** texts and supply masks that match your own photo, and the same chain repaints any three regions in order — paint large or background regions first, small foreground objects last.

All three passes use Nano Banana Edit for a grounded reason, not a preference: the nanoodle editor only offers the Inpaint node the models on its verified INPAINT_OK allowlist (live-tested 2026-06-26, method and measurements in proof/inpaint-mask-verification.md in the nanoodle repo). Models earn the list by repainting the masked region while leaving pixels outside it essentially untouched; several models that advertise inpainting were measured repainting the whole frame and are excluded. Nano Banana Edit is on the list. If you swap the model in ⚙️ settings, stay on that allowlist or the mask stops meaning anything.

Masks: supply them as PNG inputs headlessly, one per region, black with white where that pass may paint. In the editor you can instead delete a Mask input and brush the mask directly onto its Inpaint node — the node derives the same mask input. Note the executor difference from the app README of nanoodle-py: the browser composites your mask onto black at the source's pixel size; the headless library passes the mask through verbatim, so headless masks must already match the photo's dimensions.

Cost is the simple part: 3 × $0.039 for Nano Banana Edit at auto size (2026-09-12 catalog snapshot, evidence/catalogs-2026-09-12.json) = $0.117, about 12¢ a run, uploads free. Prices are observations, not caps. No live run has been made with this graph yet: it is validated structurally and by a full offline mock run of the executor (which checks that pass 2 really receives pass 1's output, mask 2 and prompt 2), not by a paid run.

Honest limits: "untouched" outside the mask is a measured model behaviour on the verification harness, not a pixel-perfect guarantee on your photo — a pass re-generates its output image, so check edges at mask boundaries, where a halo or a lighting mismatch can show. Three passes also means three chances for a seam; if a region needs no repaint, the cheapest fix is a fully black mask and a prompt that describes what is already there.
