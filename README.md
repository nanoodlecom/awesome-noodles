## Run or remix

1. Choose **Open in nanoodle** below to load the workflow on your canvas. Save current work first; opening an example replaces the canvas, with Ctrl+Z available to undo.
2. Edit the supplied brief or upload the required reference photos. Add your NanoGPT key in the editor and check the estimate.
3. Run, inspect the result and save or share your version. Each paid rerun uses your balance; models, prices and results can change.

**nanoodle** is a visual editor for AI workflows: connect text, image, video, audio and LLM nodes into a graph. Your key stays on your device; model requests go directly to the provider. The full graph travels in the share link's URL fragment, without an upload to a nanoodle backend. This repo's [link checker](scripts/check-links.mjs) verifies each link matches its committed graph.

To expose a workflow to an agent, see the [MCP tool gallery](https://mcp.nanoodle.com/); [noodle-skills](https://github.com/nanoodlecom/noodle-skills) packages selected workflows as Agent Skills.

## Run headless

The canvas is for designing. The same share link is a package: inspect it offline, then run it from Node, Python, MCP, or GitHub Actions without opening the editor. Per-graph copy-paste one-liners (regenerated from the committed JSON) live in **[recipes/](recipes/)**. Each card also has a **run headless** link beside Open in nanoodle.

Install names match the [official guide](https://nanoodle.com/guide/run-headless) — do not use `nanoodle-js` on npm:

```bash
npm i nanoodle          # JS library + `npx nanoodle` CLI
pip install nanoodle    # Python library + `nanoodle-py` / `python -m nanoodle`
```

`inspect` is **offline and free** — no API key, no network for a direct `#g=` / `#j=` / `#a=` link or a local `graphs/*.json`. `run` is bring-your-own-key: export `NANOGPT_API_KEY` (or `--key` / `--env-file`). Every `run` spends NanoGPT balance. Quote share URLs — `#` starts a shell comment.

```bash
# offline — committed file or the Open-in-nanoodle URL
npx nanoodle inspect graphs/favicon.noodle-graph.json
nanoodle-py inspect graphs/favicon.noodle-graph.json

# spends balance — paste the share URL from the recipe (or Open in nanoodle)
export NANOGPT_API_KEY=...
npx nanoodle run "<share-url>" --out ./out
nanoodle-py run "<share-url>" --out ./out
```
