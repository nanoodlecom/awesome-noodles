Every entry includes an editable graph, a chosen model and a real saved result or finished application.

## Run or remix

1. Choose **Open in nanoodle** below to load the workflow on your canvas. Save current work first; opening an example replaces the canvas, with Ctrl+Z available to undo.
2. Edit the supplied brief or upload the required reference photos. Add your NanoGPT key in the editor and check the estimate.
3. Run, inspect the result and save or share your version. Each paid rerun uses your balance; models, prices and results can change.

**nanoodle** is a visual editor for AI workflows: connect text, image, video, audio and LLM nodes into a graph. Your key stays on your device; model requests go directly to the provider. The full graph travels in the share link's URL fragment, without an upload to a nanoodle backend. This repo's [link checker](scripts/check-links.mjs) verifies each link matches its committed graph.

To run the same graphs headlessly, use [nanoodle-js](https://github.com/nanoodlecom/nanoodle-js) or [nanoodle-py](https://github.com/nanoodlecom/nanoodle-py). To expose a workflow to an agent, see the [MCP tool gallery](https://mcp.nanoodle.com/); [noodle-skills](https://github.com/nanoodlecom/noodle-skills) packages selected workflows as Agent Skills.

## Limitations

- **Samples show observed results.** Twelve workflows have saved generated outputs; the character workflow has a playable game. Video review samples frames, and audio assessment is model-assisted. Review the linked media yourself before choosing a workflow.
- **Model ids are pinned, not permanent.** All curated model nodes have explicit IDs. The public NanoGPT catalog was checked on 2026-09-05; models and prices can change. See the [curation audit](CURATION.md) for model rationale and output acceptance checks.
- **Costs are estimates.** Entries state media-step prices where available. Text calls, audio length, settings and reruns can add cost; check the editor estimate before running.
- **Link tests and output review are separate.** `npm test` proves each link reproduces the committed graph. The [sample gallery](https://nanoodle.com/examples/gallery/) records actual output reviews and their limits; neither guarantees a future generation.
