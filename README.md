# awesome-noodles 🍜

Twenty-five workflows for [nanoodle](https://nanoodle.com): models pass images, stories, motion and sound to one another to make something you can play, watch or remix. Open one, change its inputs, and run with your NanoGPT key and balance. Viewing the [saved results](https://nanoodle.com/examples/gallery/) is free; opening a workflow does not run it.

- **Humanize a comment** — Five writers (Qwen3.8 Novelist, DeepSeek V4.1 Flash, Cydonia-24B v4.3, Qwen3.8 antislop and Mercury 3), each with its own voice, rewrite a stiff draft reply in Nano Maxi's voice (flow v2.7); a GLM-5.3 decider checks each rewrite for faithfulness (who said what, no new facts), ranks them and picks the most human faithful one, or keeps the original. Returns one JSON object {winner, text, why, ranked}, where ranked lists all five writers with faithful, disqualified and reason (on mcp.nanoodle.com also each writer's model and exact text; a standalone graph run returns writer letters only, plus the winner's text) (typical run ~$0.003 before the 20% markup, ~$0.0036 after; hosted deposit pinned at $0.05428204, about 0.163 XNO plus a small matching tag at $0.333/XNO; the XNO amount moves with the rate). Draft and Context are required, and Guidance is optional (default "a friendly, specific reply"). The writer and decider prompts and the block labels are locked, so they aren't tool args. Each writer has a 60 s timeout and is skipped on failure, so the decider still runs on the survivors and returns ORIGINAL if all five fail. This needs a nanoodle engine with per-node timeout, skip and lock support (nanoodle-js #46).
